# 🔐 Laravel Password Generator Website

A simple and secure **password generator website** built with **Laravel** and **TailwindCSS**.  
This project is designed as a one-page landing site with a password generator tool, About section, Contact, Blog, and FAQ.  

---

## 🚀 Features
- Generate strong random passwords instantly  
- Options for:
  - Password length (default: 16)  
  - Uppercase / Lowercase letters  
  - Numbers and Symbols  
  - Exclude ambiguous characters  
- Responsive landing page layout  
- Navigation menu (Home, About, Blog, FAQ, Contact, Generator)  
- FAQ and Blog placeholder sections  
- SEO optimized (meta tags + favicon)  
- Reset button to clear settings and start fresh  

---

## 🛠️ Installation

Clone the repo and install dependencies:

```bash
git clone https://github.com/<username>/<repo>.git
cd laravel-password-generator
composer install
```

Copy environment file:
```bash
cp .env.example .env
```

Generate app key:
```bash
php artisan key:generate
```

Run the server:
```bash
php artisan serve
```

The site will be available at:
👉 http://127.0.0.1:8000
